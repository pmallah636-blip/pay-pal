# Northstar Studio Portfolio Website (DEMO)

This is a fictional static website submission created for the PayMind AI Delivery Check demonstration.

## Included files
- `index.html` — Home page
- `services.html` — Services page
- `contact.html` — Contact page
- `assets/styles.css` — Shared responsive styling
- `assets/contact.js` — Client-side required-field validation and confirmation

## Run locally
Open `index.html` in a browser. The contact form performs client-side validation and shows an in-page confirmation. It does not send data to a server or email service.

## Demonstration scope
This bundle is intentionally small and text-based so PayMind can inspect its source evidence. The AI report is not a functional test, security audit, or proof that every acceptance criterion is met.
